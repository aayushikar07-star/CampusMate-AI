# 🎓 CampusMate AI

**An AI-powered academic assistant designed to help students understand, organize, and manage their study materials.**

CampusMate AI aims to make everyday academic tasks easier by using AI to analyze study materials, answer questions from notes, and identify important academic information.

## 🚀 Problem Statement

Students often spend a lot of time going through lengthy PDFs, notes, and college notices to find important information.

CampusMate AI addresses this problem by providing a simple platform where students can upload their academic documents and use AI to extract useful information from them.

## 💡 Key Features

### 📄 Study Material Analyzer

Upload a PDF containing study material and extract its text for further AI-based analysis.

### 🤖 AI-Powered Summarization

Generate concise summaries and important points from lengthy study materials.

### 💬 Ask Your Notes

Ask questions about uploaded study material and get answers based on the document.

### 📝 Exam-Oriented Questions

Generate important questions from study materials to help students prepare for examinations.

### 📅 Smart Notice Analyzer

Analyze college notices and extract important information such as events, examinations, assignments, and deadlines.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **AI:** Generative AI API
* **PDF Processing:** PyPDF
* **Database:** SQLite
* **Version Control:** Git & GitHub

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aayushikar07-star/CampusMate-AI.git
cd CampusMate-AI
```

### 2. Install dependencies

```bash
py -m pip install -r requirements.txt
```

### 3. Run the application

```bash
py app.py
```

### 4. Open in your browser

```text
http://127.0.0.1:5000
```

## 🔐 Environment Variables

API keys and other sensitive information should be stored in a `.env` file and should **never be committed to GitHub**.

The `.env` file is excluded using `.gitignore`.
